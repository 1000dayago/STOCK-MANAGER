# 주식 관리 (HTML 앱)

분할매수 순번별 손익·평단가·매도 시뮬레이션·백테스트를 PC/모바일에서 쓰는 순수 HTML/JS 앱입니다. 빌드 과정이 없고 GitHub Pages로 그대로 배포됩니다.

## 기능
- **홈 탭**: 자산 요약, 종목 카드(순번 요약), 현재가 한 번에 입력(입력일 표시), 다가오는 일정, 최근 매매, 종목 비중
- **매매 사유 에디터**: 매수 순번·매도 기록·종목마다 글쓰기 (글꼴/크기/굵게/색/형광펜/정렬/목록/표/링크/템플릿, 사진 여러 장), 매매 일지로 복기, 인쇄/PDF
- 종목 일정(실적 발표·배당 등), 바로가기 링크(설정에서 수정), 액면분할 조정
- 종목마다 탭, 매수할 때마다 순번(1번, 2번…) 기록 · 수정/삭제 · 분할/병합(병합 취소 가능)
- 전체 평단가, 순번별 수익률, 해외주식은 매수/매도 환율 반영(달러·원화 동시 표시)
- 매도/시뮬레이션: 순번을 직접 골라 수량 지정, 선입선출/고가순/저가순/평단 비례 비교, 수수료·세금 자동 계산
- 손익 보기: 월별·연도별·종목별·기간 합계, 해외 양도세 추정, 평가손익
- 평단가 계산기, 목표 평단 역산, 손익분기 매도가
- 백테스트: CSV 불러오기, 조건 자유 조합(거래량·이동평균·볼린저·RSI·MACD·신고가·등락률·렌코·분할매수·트레일링·외국인/기관 수급), 전략 저장·비교, 기간 분할 검증, 단순 보유와 비교
- Firebase 동기화(Google/이메일 로그인) + JSON 백업

## 배포 (GitHub Pages)
1. 이 폴더의 파일을 공개 저장소에 올립니다.
2. 저장소 Settings → Pages → Source: `main` 브랜치, `/ (root)`.
3. `https://아이디.github.io/저장소이름/` 주소로 접속 → 휴대폰은 “홈 화면에 추가”.

## Firebase 준비
앱의 **설정 화면 → “Firebase 준비 방법”** 에 단계가 있습니다. 요약:
Authentication(Google, 이메일/비밀번호) 사용 → 승인된 도메인에 `아이디.github.io` 추가 → Firestore 생성 → `firestore.rules` 내용을 규칙에 게시 → 웹 앱 `firebaseConfig`를 앱 설정에 붙여 넣기.
**규칙을 게시하지 않으면 데이터가 보호되지 않습니다.**
