# data/ — 자동 수집 결과

`tools/collect.js`가 GitHub Actions에서 채우는 폴더입니다. 직접 고치지 마세요(`watchlist.json`만 직접 편집).

- `watchlist.json` 수집할 국내 종목 `{"years":3,"stocks":[{"code":"015760","name":"한국전력"},{"code":"003490","name":"대한항공","years":5}]}`
  - `years`: 일봉 시세를 몇 년치 받을지(1~15, 기본 3). 앱 설정 › 자동 수집의 “시세 수집 기간”이 이 값을 만들어 줍니다. 종목 줄에 `years`를 따로 쓰면 그 종목만 다르게 받습니다. 환경 변수 `COLLECT_YEARS`는 목록에 기간이 없을 때의 기본값입니다.
  - 기간을 늘리면 다음 수집 때 더 과거가 채워지고, 줄여도 이미 받은 데이터는 지우지 않습니다. 이어받을 때는 최근 1주일만 다시 받습니다.
- `prices/<코드>.csv` 일봉 시세. 공공데이터포털 키(`DATA_GO_KR_KEY`)가 있으면 그것을, 없으면 네이버 모바일 증권(비공식 주소, 키 불필요)에서 받습니다. 수정주가 여부는 확인되지 않았습니다. 장 마감(한국시간 16시) 전의 당일 값은 받지 않습니다. 네이버 시세는 `COLLECT_PRICE_NAVER=0` 으로 끕니다.
- `flow/<코드>.csv` 외국인·기관·개인 순매수(단위: 주, 키 불필요). 네이버 모바일 증권(비공식 주소)에서 매번 최근 60거래일을 받아 날짜별로 이어 붙입니다. 수집을 쉰 기간은 비며, 형식이 바뀌면 수급 항목만 실패로 기록됩니다. 끄려면 `COLLECT_FLOW=0`
- `dart/<코드>.json` 최근 공시, `fin/<코드>.json` 재무 요약 (DART)
- `news/<코드>.json` 뉴스 헤드라인 (네이버 검색 API)
- `status.json` 마지막 수집 결과(성공/오류)
