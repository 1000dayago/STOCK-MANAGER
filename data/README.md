# data/ — 자동 수집 결과

`tools/collect.js`가 GitHub Actions에서 채우는 폴더입니다. 직접 고치지 마세요(`watchlist.json`만 직접 편집).

- `watchlist.json` 수집할 국내 종목 `{"years":3,"stocks":[{"code":"015760","name":"한국전력"},{"code":"003490","name":"대한항공","years":5}]}`
  - `years`: 시세·수급을 몇 년치 받을지(1~15, 기본 3). `from`/`to`(`YYYY-MM-DD`)를 쓰면 그 날짜 구간을 받고 `years`보다 우선합니다(`to`를 비우면 오늘까지). 앱 설정 › 자동 수집의 “수집 기간”이 이 값을 만들어 줍니다. 종목 줄에 `years`·`from`·`to`를 따로 쓰면 그 종목만 다르게 받습니다. 환경 변수 `COLLECT_YEARS`는 목록에 기간이 없을 때의 기본값입니다.
  - 기간을 늘리면 다음 수집 때 더 과거가 채워지고, 줄여도 이미 받은 데이터는 지우지 않습니다. 이어받을 때는 최근 1주일을 다시 받아 보정합니다. `to`가 과거 날짜이고 그 구간이 이미 있으면 다시 받지 않습니다.
- `prices/<코드>.csv` 일봉 시세. 공공데이터포털 키(`DATA_GO_KR_KEY`)가 있으면 그것을, 없으면 네이버 모바일 증권(비공식 주소, 키 불필요)에서 받습니다. 수정주가 여부는 확인되지 않았습니다. 장 마감(한국시간 16시) 전의 당일 값은 받지 않습니다. 네이버 시세는 `COLLECT_PRICE_NAVER=0` 으로 끕니다.
- `flow/<코드>.csv` 외국인·기관·개인 순매수(단위: 주, 키 불필요). 네이버 모바일 증권(비공식 주소)에서 시세와 같은 수집 범위만큼 받습니다. 한 번에 60거래일씩 날짜 기준(`bizdate`)으로 과거까지 이어 받고(대한항공은 2012-03까지 확인), 이후에는 마지막 날짜 근처부터 이어 받아 수집을 쉬어도 사이가 비지 않습니다. 형식이 바뀌면 수급 항목만 실패로 기록합니다. 끄려면 `COLLECT_FLOW=0`
- `dart/<코드>.json` 최근 공시, `fin/<코드>.json` 재무 요약 (DART)
- `news/<코드>.json` 뉴스 헤드라인 (네이버 검색 API)
- `status.json` 마지막 수집 결과(성공/오류)

## 수집 대상 반영(이슈 방식)
앱 설정 › 자동 수집의 **수집 대상 반영** 버튼은 `수집 대상 반영` 제목의 GitHub 새 이슈 화면을 엽니다(목록이 JSON으로 미리 채워짐). 초록색 **Create**(구버전 화면은 Submit new issue) 버튼을 누르면 `.github/workflows/watchlist-issue.yml`이 `tools/watchlist-issue.js`로 목록을 검증해 `data/watchlist.json`을 갱신하고, “자료 수집”을 바로 실행한 뒤 결과를 댓글로 남기고 이슈를 닫습니다. 저장소 소유자가 연 이슈만 처리하고, 앱이 만든 표시가 없거나 목록이 비어 있거나 형식이 틀리면 기존 목록을 그대로 둡니다. 종목별 `years`/`from`/`to`는 이슈에 없으면 기존 값을 유지합니다. 토큰은 쓰지 않습니다.

## 앱에서 쓰는 방법
시뮬레이션의 “저장된 데이터” 목록에 수집된 종목이 **“○○ · 자동 수집”**으로 자동으로 나타납니다. 고르면 `prices/`와 `flow/` 파일을 읽어 시세·수급을 한 데이터로 만들어 쓰며, 내 기기에 복사해 저장하지 않으므로 수집이 돌 때마다 새 날짜가 저절로 늘어납니다(열려 있는 화면은 “저장소 새로고침”으로 갱신). 개인 CSV와 합치거나 오프라인으로 쓰려면 “자동 수집 데이터를 내 기기에 복사”를 씁니다.

## 종목 검색 목록 (`stocks.json`)
`tools/build-stocklist.js`가 네이버 증권(비공식 주소)에서 코스피·코스닥 전체(주식·ETF·ETN, 약 4,300개)를 받아 `data/stocks.json`으로 저장합니다(`.github/workflows/stocklist.yml`, 매주 일요일·수동 실행 가능). 앱의 종목 추가·수정 창이 이 파일로 이름·초성·코드를 검색해 이름·코드·시장을 채웁니다. 형식: `{"updatedAt","count","stocks":[[코드,이름,시장(P=코스피,Q=코스닥),종류(s=주식,e=ETF,n=ETN)],…]}`(시가총액 큰 순). 코드는 숫자 6자리 또는 숫자·영문 대문자 6자리(예: `0126Z0`)입니다. 받은 종목이 3,000개 미만이면 기존 파일을 그대로 두고 실패로 끝납니다.
